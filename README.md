# pace

A local-first command-line time tracker for work and daily life.

This is the restart of pace, codename **pace-ng**. When it is ready, it is
published as the next major version of `pace-rs`. The previous code base
(last release 0.15.2) is archived.

Nothing is built yet. The plan is the internal design proposal *Restarting
pace* (`src/proposals/restart.md` in the design-docs repository).
